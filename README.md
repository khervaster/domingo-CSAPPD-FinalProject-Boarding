# DomingoBoardingManagement

Domingo's Boarding House Management System

DoManage

## Features
Boarding House Full CRUD Operations: 
        > Create 
        > View 
        > Search/filter 
        > Sort
        > Update 
        > Delete

Boarding Rent + Utility Billings
    Utility & Rent Billing: 
        > Track 
            > Rent Amount
            > Electricity Bills 
            > Water Bills
            > Payment Statuses 
            > Due dates of these bills

Water Delivery Requests: 
        > Submit + monitor 
            > drinking water container delivery requests per room

Access:
    > For demo purposes, only a button will switch the view between the boarder and the management 

## DoManage's Tech Stack
Frontend: Angular
Backend: Node.js, Express, Mongoose, CORS, Dotenv
Database: MongoDB Atlas (free tier)
